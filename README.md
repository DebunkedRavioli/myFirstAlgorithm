# myFirstAlgorithm
Accelerated Class Year 10 Term 1 Task #A3

Canteen Lunch Orders Code

My code helps students order lucnh online using an algorithm which uses three functions. calculateTotal, applyDiscount and Display Reciept.

These functions allow the user to have a simple interface into the school canteens menu and it is all looped so after the first function the user can always go back and add more items if they need to. The use of the applyDiscount feature makes it so that if mroe than $10 is spent the TotalCost is reduced by 10% making it more affordable to the user. Finally the Display reciept fucntion is there for proof of purchase as well as ordering refunds on orders. These three function make the interface smooth and reliable which in turn boost sales for the School Canteen.
